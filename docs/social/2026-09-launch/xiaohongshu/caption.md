# 发布标题

把 Navidrome 变成一起听歌房

# 正文

最近我们把原来的一起听歌能力，做成了一个可以安装在 Navidrome 旁边的开源项目：**Navidrome Music Room**。

它想解决的事情很简单：音乐都在自己的服务器里，但想和异地朋友、家人一起听时，总不能靠“3、2、1，一起按播放”吧 😂

现在管理员可以从 Navidrome 的插件页面进入房间管理界面，创建房间，再生成邀请链接或二维码。朋友打开链接，用自己的 Navidrome 账号登录，就能直接在电脑或手机浏览器里加入。

目前的 `v1.1.0-dev` 已经可以：

- 按歌曲、专辑、歌手浏览和搜索 Navidrome 曲库
- 点一首歌，或者把整张专辑加入共同队列
- 同步播放、暂停、进度跳转、切歌和刷新重连
- 创建与管理房间、邀请和成员
- 让每个成员继续使用自己的曲库权限

我们没有把音频转发到房间服务器。房间只同步队列和播放状态，歌曲、封面、歌词仍由每位用户直接向 Navidrome 请求；房间数据也单独保存在插件目录下，不会混进 Navidrome 数据库。

当前 Navidrome 官方插件接口还不能原生往左侧栏或歌曲详情页插入按钮，所以现在是从插件的 **Website** 入口进入管理界面，再通过分享链接进入 Web 听歌房。我们把这层限制和伴生网关的安装方式都写在 README 里了。

项目刚进入第一个公开开发版本，很适合找问题。如果你也在用 Navidrome，欢迎装到自己的实例里测试一下，给仓库点个 Star，或者直接提交 Issue / PR 🙌
