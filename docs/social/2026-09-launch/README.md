# v1.1.0-dev social launch kit

Editable, source-controlled material for introducing Navidrome Music Room as
its repository authors. Nothing in this directory has been posted to an
external platform.

## Xiaohongshu

- `xiaohongshu/cards.html` — editable 1080 × 1440 HTML source
- `xiaohongshu/cards/01.png` … `08.png` — posting-order exports
- `xiaohongshu/contact-sheet.png` — editorial overview
- `xiaohongshu/caption.md` — title, caption, tags and alt text

The cards were rendered with the public
[Xiaohongshu HTML Cards skill](https://gitlab.muiao.com/skills/xiaohongshu-html-cards).

## WeChat Official Account

- `wechat/article.md` — canonical article copy
- `wechat/article.html` — styled narrow-screen delivery
- `wechat/article-preview.png` — browser-rendered review proof

The article follows the public
[WeChat Technical Article skill](https://gitlab.muiao.com/skills/wechat-technical-article).

## Public-safe asset

`assets/admin-ui-public.html` creates `assets/admin-ui-public.png` from the real
room administration capture while excluding obsolete lower-page content and
hiding the test LAN address and invitation token. Keep the HTML source when
updating the screenshot so that the redaction remains reviewable.
